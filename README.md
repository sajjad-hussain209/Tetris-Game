# Tetris Game

A Tetris game developed in **C++** with a graphical user interface using the **SFML library**.

This project was developed as a **first-semester programming project** to practice C++ programming, game logic, and GUI development.

## Technologies Used

- C++
- SFML
- Object-Oriented Programming

## Features

- Tetris gameplay
- Graphical user interface
- Different Tetris pieces
- Piece movement and rotation
- Collision detection
- Line clearing
- Score tracking

## Project Structure

- `main.cpp` — Main program
- `pieces.h` — Tetris piece definitions
- `functionality.h` — Game functionality
- `utils.h` — Utility functions
